# Assignment 4: Forms and Validation

Student: Sapayev Farkhod

Group: SE-2525

## Description

This project demonstrates HTML forms, HTML5 validation,
Bootstrap styling, and JavaScript validation.

## Pages

- index.html — basic contact form.
- validation.html — contact form with HTML5 validation.
- bootstrap-form.html — contact form styled with Bootstrap Grid.
- bootstrap-validation.html — Bootstrap success and error feedback.
- registration.html — responsive registration form.

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open index.html in a browser or use VS Code Live Server.
3. Use the navigation bar to switch between pages.

An internet connection is required to load Bootstrap.

## Validation

- Required fields cannot be empty.
- Email fields require a valid email format.
- Names and messages have length limits.
- Registration passwords require at least 8 characters.
- Password and confirmation must match.
- Gender and country must be selected.
- Hobbies are optional.
- Reset clears the registration form and validation feedback.

## Notes

This is a frontend demonstration.
Messages are not emailed, and accounts are not created.
